Organizing and Analyzing Quantitative Research Data

This instructional module guides graduate researchers and advanced students through cleaning, structuring, and screening raw experimental datasets before migrating them into dedicated statistical software.

Core Competencies You Will Develop

  • Clean and standardize tabular raw data in Excel for systematic inquiry.
  • Isolate categorical factors by engineering binary/dichotomous variables (dummy coding).
  • Compute descriptive summaries using the Excel Analysis ToolPak.
  • Import refined datasets into statistical software (PASW/SPSS) for inferential testing.

Prerequisites & Technical Requirements

Software Required:

  • Microsoft Excel (with Analysis ToolPak enabled)
  • PASW / IBM SPSS Statistics (or campus lab access)

Foundational Concepts:

  • Basic spreadsheet manipulation and cell referencing
  • Independent vs. dependent variable identification
  • Elementary statistical terms (mean, variance, distribution)

Lesson Outline

  1. Data Standardization and Dummy Coding
  2. Generating Descriptive Summaries in Excel

1. Data Standardization and Dummy Coding

Begin by opening the companion workbook: 📥 Download sample dataset (data-lesson-tutorial.xlsx) .

  1. Define strict variable names: In the Raw_Dataset tab, verify that Row 1 contains only unique variable names. Replace 4tutorial_types with tutorial_types (variable headers must start with a letter and avoid special characters).
  2. Use descriptive, unambiguous labels: Replace ambiguous headers such as use and useful with perc_ease_of_use and perc_usefulness respectively.
  1. Enforce consistent input conventions: In the gender column, normalize values so that entries like female are coded consistently as F.
  2. Decompose compound variables: When columns contain aggregated responses (such as tasks_completed storing Y/Y/N), split them into atomic attributes: task1, task2, and task3. Once validated, remove the redundant composite column.

Statistical Principle: Dichotomous Coding

Recoding categorical factors into binary indicator variables (0 = Absent / No, 1 = Present / Yes) enables linear models and non-parametric algorithms to isolate the independent effects of discrete levels (e.g., comparing low experience against high experience).

  1. Generate the analysis sheet: Duplicate Raw_Dataset to a new tab named Formatted_Data.
  2. Expand categorical values into binary columns: Use Insert > Columns to add columns for each level in nominal categories (e.g., tutorial_types, gender, exp_level).
  3. Recode values: Using Edit > Replace (Ctrl+H / Cmd+H), convert values to binary 1 and 0.

2. Generating Descriptive Summaries in Excel

Diagnostic Observation

Inspect dispersion before hypothesis testing. If perc_enjoy displays high central tendency while perc_usefulness exhibits severe variance, explore whether user engagement is decoupled from utility.

  1. Arrange continuous data: Group continuous numerical columns (such as perc_enjoy, perc_usefulness, and perc_ease_of_use) into contiguous columns.
  2. Enable the Analysis ToolPak: Navigate to Tools > Add-Ins..., check Analysis ToolPak, and click OK.
  3. Execute Descriptive Statistics: Navigate to Tools > Data Analysis, choose Descriptive Statistics, enter your numeric range (e.g., H2:J26), check Summary Statistics, and output to a new tab named Descriptive_Stats.

3. Performing Inferential Tests in PASW/SPSS

Launch PASW (SPSS). From the prompt screen, select Open an existing data source > More Files.... Set the format dropdown to Excel (*.xls, *.xlsx), browse to your file, and import the Formatted_Data worksheet.

Methodology Check

Always confirm variable scaling (nominal, ordinal, interval, or ratio) and distribution normality before choosing a test. For non-normally distributed samples comparing k-independent groups, non-parametric procedures like Kruskal-Wallis are recommended.

  1. Launch Kruskal-Wallis: Navigate to Analyze > Nonparametric Tests > K Independent Samples....
  2. Assign variables: Move perc_usefulness to the Test Variable List (dependent measure) and free_play to the Grouping Variable field (independent measure).
  3. Set group range: Click Define Range..., enter 0 for Minimum and 1 for Maximum, then click Continue.

Click OK to execute the computation. In the Output Viewer, review your test statistic, degrees of freedom, and asymptotic significance ($p$-value).

Archiving Output

Preserve your analytical trail by exporting raw outputs outside proprietary software: navigate to File > Export and save reports as PDF, Word, or plain text.
